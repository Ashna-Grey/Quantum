Protocol architecture

The dashboard keeps quantum verification, statistical evidence, and classical session controls visibly separate.

Layer 1
Quantum State Preparation
Generate Pauli eigenstates that represent the public quantum key.
Layer 2
Teleportation
Transport the simulated public states using Bell measurement and Pauli correction.
Layer 3
Signature & Measurement
Use the signed basis/eigenvalue and measure the selected state.
Layer 4
Statistical Analysis
Count mismatches and compare them with the configured verification rule.
Layer 5
Security Verdict
Return an explainable decision with supporting evidence.

QDS Protocol Lab

Run the protocol from key generation to projective measurement. The selected attack changes the protocol inputs, not just a final label.

What changes? The backend generates the quantum public states, teleports them, creates the signature, measures the selected states, and counts mismatches. Attacks modify the protocol path before verification.

What the backend does

Generate Pauli states → teleport public states → create a signature → select states using the message → measure → count mismatches → decide.

OUTPUT

What you should read

Decision, mismatch evidence, teleportation fidelity, block-level results, exposure quantities, and Bell-witness behavior.

Decision dictionary

Use these meanings when presenting the dashboard.

ACCEPT

The measurements are consistent with the configured legitimate model and verification threshold.

REJECT_FORGERY

At least one message block produces evidence inconsistent with the legitimate signature expectation.

REJECT_IMPERSONATION

The signature was generated from unrelated signing information and does not verify against the legitimate public key.

REPLAY

The signature can be cryptographically valid while the session itself is stale or already consumed.

UNAUTHORIZED

The requested verifier does not match the registered verifier for the key.

ABORT / CHANNEL

The channel evidence is abnormal enough that distribution should not proceed in the modeled scenario.

What the simulator does not prove

This should be stated clearly in the SIH presentation.

The software is a protocol-level simulator. It demonstrates mathematical state evolution and statistical behavior; it does not by itself prove information-theoretic security or certify the behavior of a physical quantum channel.
